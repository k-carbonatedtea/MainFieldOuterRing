# Main Field Outer Ring

Explore an extra kilometer of Hyrule in every direction in *The Legend of Zelda: Breath of the Wild*. Main Field Outer Ring adds 40 playable chunks around the original 80, bringing the overworld to 120 chunks.

- The game streams each new chunk through its ordinary map system, with its own object placement, decoration resources, and terrain collision. The original 80 chunk names and coordinates stay the same.
- The playable boundary moves outward to X ±6,000 m and Z ±5,000 m, with boundary winds starting 80 m inside the new edge. The map cursor and panning reach the expanded area.
- The outer ring has four climates. The north is cooler, the south is warm and wet, the west is dry, and the east is mild.

The new areas are for terrain exploration, with no new NPCs, quests, or NPC navigation meshes.

Walk past the former world boundary to reach the new terrain. For example, B-9 is south of the Gerudo region.

## Install on Switch

Requires the Nintendo Switch release of *Breath of the Wild* with update **1.9.0**, Atmosphère, and main executable Build ID `CD57B23FA4BBAD65803D9788C01821EE00000000000000000000000000000000`.

If upgrading from an earlier release, replace its map IPS and map resources together.

1. Close the game and extract `MainFieldOuterRing-1.9.0-NS.zip`.
2. Copy the included `atmosphere` folder to the root of your SD card.
3. Restart the game.

## Compatibility

Install `MainFieldOuterRing+TravelMedallion10-1.9.0-NS.zip` when using both mods. The combined package merges their Resource Size Table (RSTB) entries. Installing the standalone packages over each other overwrites that shared table.

Other mods that replace the same map archives, ActorInfo, or RSTB need their resources merged. The included `manifest.json` lists this package's resource overrides. Save inside the original map before removing the expansion.
